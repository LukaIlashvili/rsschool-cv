Code Example

Task: Complete the square sum function so that it squares each number passed into it and then sums the results together.

For example, for [1, 2, 2] it should return 9 because 12 + 22 + 22 = 9.


function squareSum(numbers){
  const squaredNums = numbers.map(n => n ** 2)
  const finalSum = squaredNums.reduce((acc, n) => acc + n, 0)
  return finalSum
}
